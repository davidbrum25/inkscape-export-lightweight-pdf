## TLDR, step by step

1. When a document holds high-resolution photos, renders, or storyboard panels, Inkscape often writes a PDF of 50 to 100 MB or more, because Cairo embeds the raster images with little or no lossy compression.

2. This extension exports that PDF and recompresses those images to a resolution you choose. Vector paths, text, fonts, and layout stay untouched.

3. The extension is called **Export Lightweight PDF**.

4. How it works: Extensions → Export → Export Lightweight PDF. Pick a preset (**SD** 50% / about 75 DPI, **Screen** about 96 DPI, **Draft** 25% / about 50 DPI, **HD** 75% / about 150 DPI, or **Print** 300 DPI), set JPEG quality, leave the output folder empty to save next to the SVG, and click Apply.

5. A report shows the size before and after, and the percentage saved. Typical savings reach 95%.

6. Transparent images can be stored as JPEG plus an alpha mask, so cutouts stay clean and the file stays small.

7. Developed and tested on Inkscape 1.4. Requires Inkscape 1.2 or newer.

8. The repo is public: https://github.com/davidbrum25/inkscape-export-lightweight-pdf
   License is GPL-2.0-or-later, matching Inkscape's own extensions.

9. Install is a clone into the user extensions folder, then restart Inkscape:

   ```bash
   git clone https://github.com/davidbrum25/inkscape-export-lightweight-pdf.git \
     ~/.config/inkscape/extensions/export-lightweight-pdf
   ```

   On Windows that folder is `%APPDATA%\inkscape\extensions`.
